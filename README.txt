Student Grade Analyzer

Run: python student_grade_analyzer.py
Use python3 if needed. No external packages are required.

students.csv loads at startup and saves after adding, editing or removing.
Menu 6 exports ranked records to class_report.csv. Re-export after edits.
Menu 5 exits. Saved changes persist across restarts.
CSV files live beside the Python script.
If students.csv is missing, the program creates five starter records.
Invalid CSV data stops startup without overwriting the file.
Class and subject statistics display in the terminal.
